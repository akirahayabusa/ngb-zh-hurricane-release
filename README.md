## 使用方法

1. 准备原版美版镜像，改名为 `NINJA GAIDEN BLACK.iso`，先核对校验值：
   - 大小：6,276,317,184 字节
   - SHA-1：`d35859d1f3a43ce793dbe3e914a5188f4e83ad67`
2. 下载对应版本的发布包并解压，把原版镜像放进解压出的文件夹。
3. 双击 `打补丁.bat`（日英版为 `パッチ適用.bat`），等 1–3 分钟，文件夹里会生成新镜像（原版镜像不会被修改）。各版本生成镜像的校验值见包内 `说明.txt`。
4. 用 xemu 或 Xbox 360 加载生成的镜像。xemu 打不开时把文件名改成纯英文、不带括号。**第一次启动会重新安装缓存，约 7 分钟，期间请勿关机。**
